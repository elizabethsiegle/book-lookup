Book Lookup settings

Passwords

By default, Book Lookup never sees or stores your passwords. Save your SFPL, Goodreads and StoryGraph logins in Chrome's own password manager. This extension opens a search results page; if the site redirects you to a login page instead, it focuses the username field so Chrome's autofill suggestion is one click away.

Autofill (opt-in, per site)

Saving a credential for a site below lets Book Lookup fill that site's login form for you — it does not submit the form; you press Enter. This is off for every site until you save a credential for it here, and it can be turned back off at any time with Clear.

These values are stored unencrypted on disk. Chrome extensions have no access to the operating system's keychain, so there is no honest way to encrypt them at rest here — anyone with access to this computer, or to a backup or sync of this Chrome profile, can read them.
